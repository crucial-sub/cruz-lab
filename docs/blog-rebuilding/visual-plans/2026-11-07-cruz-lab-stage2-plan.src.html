지금 서버는 요청마다 외부 REST로 이메일을 비교한다.

관리자 API 호출마다 Identity Toolkit에 HTTP 1회. 이메일 문자열만 비교한다. 이 파일을 지운다.

지금 에디터 페이지는 prerender라서 서버 검사를 거치지 않는다.

prerender 페이지는 미들웨어를 거치지 않는다. 관리자 페이지를 모두 prerender = false로 바꾼다(A10).

이미지는 서버가 webp 3종으로 줄이고, 지운 글의 이미지는 7일 뒤 정리된다.

Firestore 문서와 GitHub 백업만 지운다. Storage는 건드리지 않는다(A6).

2026-11-07 확인: 버킷 CORS 설정이 비어 있다. storage.googleapis.com 사전 요청에 허용 헤더가 없다.
